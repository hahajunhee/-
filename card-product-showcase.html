04 / 08 — FEATURE 1
04 / 08
FEATURE 01
감성적인 편지 작성
텍스트 에디터를 단순한 입력창이 아니라, 손편지 느낌이 나도록 폰트와 배경을 고를 수 있게 했어요. 읽는 사람이 받는 순간의 감정까지 고려했습니다.
💡 Tip. 단순한 textarea도 폰트 선택과 배경 장식만 더하면 완전히 다른 경험이 됩니다. 디테일이 감성을 만들어요.
CODEFIT.
05 / 08 — FEATURE 2
05 / 08
FEATURE 02
추억 갤러리
편지에 첨부된 사진들이 자동으로 타임라인 갤러리에 쌓여요. 날짜별로 정렬되어, 시간이 지나면 우리만의 작은 추억 아카이브가 됩니다.
💡 Tip. 사진을 단순 첨부 파일로 두지 말고 별도 테이블로 관리하면 다양한 뷰로 재활용할 수 있어요.
CODEFIT.
06 / 08 — FEATURE 3
06 / 08
FEATURE 03
새 편지 알림
상대가 편지를 쓰면 PWA 푸시 알림이 가요. "자기야가 편지를 보냈어요" — 받는 순간의 설렘까지 놓치지 않도록 설계했습니다.
💡 Tip. 앱 설치 부담 없이도 PWA + Web Push로 네이티브 알림 경험을 만들 수 있어요.
