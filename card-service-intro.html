03 / 08 — 거래관리
03 / 08
PROJECT 01
거래관리 시스템
엑셀 장부의 한계를 웹으로 풀어본 프로젝트. 거래처별 미수금 자동 집계, 거래명세서 PDF 자동 생성, 모바일에서도 입력 가능한 구조로 만들었어요.
💡 인사이트. 엑셀의 핵심은 "셀"이 아니라 "수식의 자동 흐름". 웹에서 트리거 + 집계 테이블만 잘 설계해도 엑셀의 답답함이 사라집니다.

04 / 08 — 재고관리
04 / 08
PROJECT 02
재고관리 시스템
입출고 내역을 실시간 추적하고, 재고 임계치 이하면 자동으로 알림을 보내는 시스템. 카카오톡 알림 연동까지 넣어 현장에서 바로 받아볼 수 있게 했어요.
💡 인사이트. 재고는 "현재 수량"보다 "변화량"이 더 중요해요. 이벤트 소싱 패턴으로 모든 입출고를 기록하면 추후 분석도 쉬워집니다.

06 / 08 — 커플 사이트

PROJECT 03
커플 편지 사이트
카톡에 묻혀버리는 편지를 위한 둘만의 웹 공간. 편지 작성, 사진 첨부, 추억 갤러리, 기념일 알림까지 하나의 흐름으로 연결되도록 설계했어요.
💡 인사이트. B2C 프로젝트는 기능보다 "감성"이 핵심. 폰트, 여백, 마이크로 인터랙션 하나하나가 사용자 경험을 만듭니다.
