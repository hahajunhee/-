사용 방법

  1. 마음에 드는 디자인의 PNG 다운로드 버튼 클릭 → 다운로드 폴더에 PNG 파일 저장됨.
  2. 이 파일을 핸드폰으로 옮깁니다 (카톡 "나에게 보내기" / AirDrop / 이메일 첨부 등).
  3. 인스타 앱 → 프로필 → 사진 변경 → 갤러리에서 다운받은 PNG 선택.
  4. 인스타가 자동으로 원형 크롭합니다. (디자인은 이미 크롭 영역에 맞춰져 있어요)
